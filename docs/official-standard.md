# 官方资料逐项标准

本文把官方页面整理成可执行标准。若本文与现场口径、实物或源码冲突，以现场最新通知、实物、当前源码和对应 OpenAPI operation 为准。

## 赛道定义

Deotaland 提供设备、真实世界感知与输出；TiDB Agent Stack 提供 Agent、状态、记忆、Skill/Tool、长任务、Artifact 与可观测性。参赛者的任务不是“让硬件能聊天”，而是赋予它一个清楚的用户、角色、交互方式和行动闭环。

开工前必须回答：

1. 设备在什么时候出现在用户身边？
2. 它必须看到、听到或记住什么？
3. 对话结束后，它继续完成什么？

## 板卡事实

四块板均基于 ESP32-S3，支持 2.4G Wi‑Fi 和 BLE 5。官方数量为 A×15、B×10、C×5、D×10。三人一组，建议分别负责硬件/固件、Agent/云端、交互/展示或结构设计。

### A：AIoT BasicV2

- 145×135 mm，2.4 英寸 ST7789 240×240。
- GC2145 摄像头、数字麦克风、ES8311 音频、SD、SHT30、SPA06、光敏、WS2812。
- 现成示例最多：语音、实时 ASR、摄像头预览/快照。
- 适合快速完成桌面多模态装置。

### B：OJBadge

- 45.8×45.8×12.3 mm，1.28 英寸圆形触摸屏。
- 麦克风、ES8311、功放、扬声器、300mAh 电池、双按键。
- 暂无现成 Agent_link 板级适配，适合有嵌入式经验并追求可穿戴外观的团队。

### C：AIoT 全功能套件

- 250×175 mm，21 类外设/27 个子模块。
- 含摄像头、六轴、PIR、测距、烟雾、环境传感、屏幕、编码器等。
- 数量最少、开发复杂；现场不提供电机。

### D：ROROLEE-Basic

- 随身机，SH8501 AMOLED 120×240。
- ES7210 双麦 AEC、ES8311 扬声器、800mAh 电池、SD、按键和震动马达。
- 有现成板级适配，但源码仍需补真实震动和文字/图形渲染。

## Agent_link 开发标准

设备通过能力位声明 MIC、SPEAKER、SCREEN、BUTTON、HAPTIC、BATTERY、LED、SENSOR、ACTUATOR、RECORDING、CAMERA。下行由回调驱动设备，上行用 `agent_link_push_*`/I/O 接口发送数据。

推荐顺序：

1. 安装 ESP-IDF v5.5.4。
2. 选择现成 Board Type 并完成编译、烧录和串口日志验证。
3. 先跑通 BLE/语音/显示中的最短路径。
4. 再增加传感器、快照、灯光或震动。
5. 最后才做复杂 UI、长任务和场景逻辑。

## Agent Stack 开发标准

核心概念：Workspace、Project、User/API Key、Agent、Session、Turn、Operation、Artifact。建议每队一个 Workspace、每个作品一个 Project、每类角色一个 Agent，每台设备或体验者使用独立 Session。

最小调用链：

1. 用 Workspace Key 创建服务用户与 User Key（若现场需要）。
2. 用 User Key 发现 Project。
3. 选择/创建 Agent。
4. 创建 Session并保存 `sessionId`。
5. 创建文本 Turn。
6. 逐行解析 NDJSON，处理进度、正式回复、错误和终止事件。
7. 把安全的结构化结果映射到设备输出。

重要降级：

- ASR 返回 501：改用手机/电脑侧 ASR，再发送文本 Turn。
- 图片模型不可用：手机/电脑侧 OCR 或图像描述后发送文本。
- Scheduler/记忆/知识库未开放：用本地任务队列和数据库状态完成 MVP。
- 连续视频不可用：使用单张快照或短片段处理。

## 交付验收

### 项目介绍

一分钟内说明名称、目标用户、真实场景、核心体验、为何需要硬件、团队分工。

### 三分钟视频

- 不超过 180 秒。
- 必须出现真实设备。
- 至少一次连续完整闭环，不能全部用动画或录屏代替。
- 可以有字幕、设备特写、串口日志和赛前备用录像。

### 一页架构图

必须出现真实输入、ESP32/外设、SDK/Agent_link、连接方式、Agent/Skill/Tool、数据流和实际输出，并区分官方提供、团队配置、团队开发。

### README 与运行说明

必须包含硬件清单、接线、版本、目录、依赖、编译/烧录/运行、Agent配置、最短验证路径、已知限制和不含凭据的 `.env.example`。

### Agent Stack 说明

说明 Agent 的输入、判断、Skill/Tool、硬件能力映射、长任务/跟进，以及脱敏后的日志或 Trace。
